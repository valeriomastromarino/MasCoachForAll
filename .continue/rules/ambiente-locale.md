- Rispondi sempre in italiano. Prima di lavorare leggi `CLAUDE.md` e `AGENTS.md`.
- Compilare l'APK: task "MasCoach: compila APK" (`npm run build:apk`) → `MasCoach.apk`. Controlli prima di chiudere una modifica: `npm run check`.
- Lavori solo dentro questa cartella. Non fare `git push`, non toccare impostazioni di sistema e non cancellare file fuori dal progetto.
- Se un'operazione richiede il cloud (Vercel, GitHub, Intervals.icu con credenziali, pubblicazione), non provare: scrivi cosa serve e fermati, la farà Claude.
